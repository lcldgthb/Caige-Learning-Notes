# 模块03 大模型产品体验（课时 15-20）— WorkBuddy 讲解

概念体系搭完后，本模块回到手感：认识国内外主流大模型，逐一上手 DeepSeek、千问、GPT、Gemini，最后小结模型的基本能力。这是从"懂概念"到"会选工具"的过渡。

---

## 15 国内外大模型简介和优势分析

### 本课核心内容
主流大模型全景图。国外：OpenAI 的 GPT 系列（综合能力标杆）、Google 的 Gemini（多模态和超长上下文见长）、Anthropic 的 Claude（长文写作与编程口碑好）。国内：DeepSeek（开源+推理能力强+成本低，2025 年现象级出圈）、阿里通义千问 Qwen（开源生态最活跃的国产模型）、字节豆包、月之暗面 Kimi（长文本）、智谱 GLM 等。选择思路：没有绝对第一，按场景选——编程看 Claude/GPT，中文和成本看国产，开源部署看 DeepSeek/Qwen。

### 知识点联系
07 课（什么是 LLM）的产品化落地，也是 16-19 课逐个上手的导览；22 课（开源与闭源）会把本课的"DeepSeek/Qwen 开源"这条线单独展开。

### 学习重点与难点
- 重点：建立"按场景选模型"的意识，而不是寻找"最强模型"。
- 难点：模型更新极快，榜单月月变。破解：记住的是选型的维度（能力/成本/开源/中文），而不是某个时间点的排名。

### 授课思路
不做榜单罗列。用"买车"类比：没有最好的车，只有最适合的车——通勤买电车、越野买 SUV。同理，列模型时每个只讲"它最擅长的一件事 + 适合谁"，选型维度用表格收束。

## 16 DeepSeek 使用姿势 & Cherry Studio 简介

### 本课核心内容
两部分：一是 DeepSeek 的使用——网页版/App 直接对话；关键是它的"深度思考（R1）"模式，会先展示一步步推理过程再给答案，适合数学、逻辑、复杂分析题。二是 Cherry Studio——一个开源的桌面客户端，可以把多家大模型的 API 集中到一个软件里用，像一个"大模型总遥控器"：一次配置，随时切换模型，还支持知识库、助手预设等功能。

### 知识点联系
15 课选了"用谁"，本课解决"在哪用"：官网直接用 vs 用聚合客户端（API 方式）。这里首次出现 API 概念（程序调用模型的接口），为 M05 的聊天模板、M14 的 Dify/RAG 实战（都要配 API）做铺垫。

### 学习重点与难点
- 重点：普通对话模式 vs 深度思考模式的适用分工——简单问题别开深度思考（慢），复杂推理必须开。
- 难点：API、API Key 对纯新手是新词。破解：API 是"给程序用的模型入口"，Key 是这把入口的钥匙+计费卡；网页版是给人用的，API 是给软件用的。

### 授课思路
对比演示：同一道逻辑题，分别用普通模式和深度思考模式提问，让学员看到推理链条的价值。Cherry Studio 现场走一遍"填 Key → 选模型 → 开聊"三步，消除对"配置"二字的畏惧。

## 17 千问使用姿势

### 本课核心内容
阿里通义千问（Qwen）的上手：网页/App 对话、文档解析（丢 PDF 让它总结）、图片理解、代码能力等。千问的差异化优势：开源版本（Qwen 系列）可以免费下载部署，是全球开发者用得最多的国产开源模型；阿里云百炼平台提供 API 和企业服务。1 小时的时长说明包含大量实操：很可能覆盖了网页端深度功能、API 调用甚至本地部署演示。

### 知识点联系
承接 16 课的产品上手线；千问的"开源可部署"属性直连 22 课（开源闭源之争）和 24 课（ModelScope 社区——阿里自家的模型社区）；M14 的 RAG 实战（129 课 Qwen3 Embedding）用的就是千问的嵌入模型。

### 学习重点与难点
- 重点：千问 = 网页产品 + 开源模型家族 + 云平台三层身份，别只当成一个聊天网站。
- 难点：网页版、开源版、API 版三种形态容易混。破解：同一道菜——堂食（网页版）、买食材回家做（开源自部署）、点外卖（API）。

### 授课思路
按"三层身份"组织讲解，每层一个最小演示：网页端传一份 PDF 让它总结（堂食）、ModelScope 上展示开源模型页面（食材）、百炼平台看一眼 API 控制台（外卖）。三层讲完，学员对"模型产品的完整生态位"就有了立体认识。

## 18 GPT 使用姿势

### 本课核心内容
ChatGPT 的深度使用：模型选择（不同版本侧重速度/推理）、自定义指令（让 GPT 记住你的偏好）、项目/对话管理、联网搜索、文件上传分析、代码解释器（让它真的运行代码算数学题）、语音对话等进阶功能。作为行业标杆，ChatGPT 的很多交互设计（如自定义指令）已成为同类产品的标配。

### 知识点联系
产品上手线的第三站。GPT 的"自定义指令"是 29 课（系统提示词）的产品化形态——你在设置里写的话，最终就是以系统提示词身份进入模型的；"代码解释器"则是 32 课（工具调用）的直观样例：模型自己决定调用 Python 工具。

### 学习重点与难点
- 重点：超越"一问一答"，学会用自定义指令和项目管理把 GPT 调教成"懂你习惯的助手"。
- 难点：功能多容易记成流水账。破解：抓住主线——所有进阶功能都在解决两类问题："让它更懂你"（自定义指令、记忆）和"让它能做更多事"（联网、代码解释器、文件分析）。

### 授课思路
按"更懂你 / 更能干"两条线组织功能演示，避免功能罗列。重点演示一个反差案例：直接问"1 到 100 里有几个质数"（可能答错）vs 让代码解释器算（必然答对）——直观展示"工具调用"的价值，为 M06 埋钩子。

## 19 Gemini 使用姿势

### 本课核心内容
Google Gemini 的使用：网页/App 对话，差异化亮点有三——超长上下文窗口（可一次性塞入整本书或长视频分析）、与 Google 生态深度集成（Gmail、Docs、Drive 里直接调用）、原生多模态（文字/图/音频/视频统一理解，而不是拼接多个模型）。

### 知识点联系
产品上手线收官。Gemini 的"超长上下文"是 140 课（Context Window）的最佳预习案例；"原生多模态"呼应 13 课；与 Google 生态集成则是 21 课（企业级产品应用）的样板。

### 学习重点与难点
- 重点：上下文窗口的实用价值——能塞下整份年报/整部论文集再提问，省去切碎材料的麻烦。
- 难点："原生多模态 vs 拼接多模态"的区别。破解：原生是"一个大脑天生会听说看"，拼接是"翻译、秘书、摄影师三个人接力"——前者对跨形式细节的理解更连贯。

### 授课思路
用一个大材演示打透超长上下文：上传一整本电子书或长视频，跨章节提问细节。再对照 16-18 课做四家产品对比表（特长/适合人群/生态），为 20 课小结做铺垫。

## 20 模型基本能力小结

### 本课核心内容
对 15-19 课的收束：主流大模型的基本能力可归纳为六类——文本生成（写）、理解问答（读）、翻译、摘要、代码、推理。同时明确边界：知识有截止日期、会编造事实（幻觉）、数学和精确计算不稳定。这决定了用它的正确姿势：创意和理解类任务放心用，事实和计算类任务必须核查或借助工具。

### 知识点联系
模块 03 收官，也是整个"基础认知篇"（M01-M03）的句号：能力清单呼应 07 课（LLM 本质），能力边界直接引出 M13（幻觉）和 M06（工具调用——正是因为模型算不准、知识会过期，才需要给它配计算器、搜索引擎这些"外挂"）。

### 学习重点与难点
- 重点：能力边界比能力清单更重要——知道它不能干什么，才知道哪里需要工具补位（这是后半门课 MCP/RAG 的存在理由）。
- 难点：学员容易产生"既然会错就什么都不敢用"的过度谨慎。破解：把它当成"极其聪明但会记错事的实习生"——初稿和思路尽管交给它，事实和数字由你把关。

### 授课思路
用"实习生说明书"的形式总结：一页纸列清"擅长/不擅长/使用须知"，学员可以截图留存。最后预告：这门课后半部分讲的 MCP、RAG、Agent，本质上都是在给这个实习生配装备、配资料、配同事。
