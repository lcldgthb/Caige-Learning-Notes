## 资料职责

### PDF

PDF 是课程事实与教学边界的主依据，用于核对：

- 课件确实覆盖了什么；
- 原有示例和教学顺序；
- 课件的术语与当前课程口径；
- 用户询问的结论是否真的来自本套材料。

### 合并复习总结

合并总结用于：

- 组织高密度复习结构；
- 定位易错点和二刷优先级；
- 保留用户在总结中加入的理解、疑问和补充说明；
- 快速定位跨章联系。

总结不是高于 PDF 的事实来源。总结中的代码、结论或用户注释与 PDF/标准冲突时必须核对。

### 通用 C++ 知识

- 修正标准错误；
- 解释课件简化说法；
- 补足理解所需的最少背景；
- 提供课件外延伸方向。

必须明确标记为“标准修正”或“课件外补充”。

## 读取策略

1. 先用 `chapter-index.md` 定位章和关键词。索引只用于定位，不代表本轮已经读取材料。
2. 再在合并总结中搜索对应标题或术语。
3. 事实性回答读取对应 PDF 页。
4. 单知识点通常只读相关页；跨章问题按知识链读取多个局部片段。
5. PDF 超过 20 页时分段读取：
   - 01：`1-20`、`21-33`；
   - 03：`1-20`、`21-29`。
6. 页码统一按读取工具返回的 1-based PDF 页码记录；若课件印刷页码不同，引用时明确写“PDF 第 X 页”。
7. 图片代码模糊、被截断或 OCR 不可靠时，不猜测缺失内容；读取上下页或结合总结核对，仍无法确认则标注不确定。
8. 水印不属于正文，不把水印文本当作知识内容。
9. `chapter-index.md` 中记录的章节范围或建议页段不等于本轮已读，不能直接据此生成页码引用。

## 缺失与降级

- PDF 缺失：可基于总结回答，但必须说明没有核对原课件。
- 总结缺失：可按 PDF 讲解，但不声称使用了用户整理的易错点或二刷重点。
- 两者都缺失：本技能失去资料驱动依据，应请求用户恢复路径或改用普通 C++ 问答。
- 文件名变化：先在父目录中寻找同编号、同主题文件，不要自动使用 08 以后的课件补位。
- 资料冲突：按 `correctness-policy.md` 处理。
