# 章节索引

## 使用规则

本文件只负责定位章节、关键词、知识关系和高风险主题，不是第二份复习总结，也不是事实裁决来源。

1. 先根据用户问题定位到一章或一条跨章知识链。
2. 再读取 `source-map.md`，到合并总结的对应标题或当前版本行区间中寻找复习结构。
3. 用户询问“课件原文、老师怎么讲、具体示例或页码”时，必须实际读取对应 PDF 页面。
4. 下文的章节范围和关键词只能帮助定位，不能证明某个结论已经由本轮阅读核对。
5. 涉及标准边界、代码行为或课件疑似简化时，读取 `correctness-policy.md` 对应风险标签。

## 总体知识地图

### 三条主线

```text
语法线：
命名空间 → 缺省参数 → 函数重载 → 引用 → 类 → 运算符重载 → 模板

对象线：
对象实例化 → this → 构造与析构 → 拷贝与赋值 → 初始化列表
→ 临时对象与拷贝省略 → 动态对象 → 模板对象 → 标准容器

资源线：
C 动态内存 → class 封装 → 构造申请 → 析构释放 → 深浅拷贝
→ new/delete → operator new/delete → 模板容器 → STL 分配器
```

| `Stack` | 01～07 | 资源类型演进：C 接口、引用、class、构造析构、深拷贝、动态内存、类模板与 STL 适配器 |

## 01：C++ 入门基础

- **资料**：`01.C++入门基础.pdf`
- **合并总结当前范围**：第 1～1446 行
- **本章主线**：从 C 语言进入 C++，掌握后续类、模板和 STL 都会反复使用的基础语法。
- **前置知识**：C 语言函数、指针、作用域、宏和基本输入输出。
- **后续连接**：引用连接拷贝控制；重载连接构造函数和运算符；命名空间连接 `std`；`nullptr` 连接类型安全接口。

### 核心主题与检索词

| 主题 | 常见检索词或用户问法 |
|---|---|
| 命名空间 | `namespace`、作用域、名字冲突、`using namespace std`、命名污染 |
| C++ 输入输出 | `cin`、`cout`、`endl`、流插入、流提取、关闭同步 |
| 缺省参数 | 默认参数、全缺省、半缺省、声明和定义、从右向左 |
| 函数重载 | overload、参数个数/类型/顺序、返回值不同、调用二义性 |
| 引用 | 别名、引用传参、引用返回、能否改绑、指针和引用 |
| `const` 引用 | 绑定临时对象、类型转换、生命周期延长、只读参数 |
| `inline` | 内联、宏函数、头文件、编译器是否一定展开 |
| `nullptr` | `NULL`、整数 0、空指针、重载选择 |

### 贯穿案例

- 用引用改写 C 风格 `Swap`。
- 用引用或指针引用改造 `Stack`、链表接口。
- 用缺省参数为 `Stack` 提供默认容量。
- 用 `nullptr` 解决空指针重载歧义。

### 高风险主题

- `COR-REF-LIFETIME`：引用绑定、临时对象和局部引用返回。
- `COR-INLINE-ODR`：`inline` 的语义与编译器是否展开不是同一问题。
- `COR-NULLPTR-OVERLOAD`：`NULL` 的实现形式与重载选择。

## 02：类和对象（上）

- **资料**：`02.类和对象(上).pdf`
- **合并总结当前范围**：第 1447～2338 行
- **本章主线**：把 C 的“结构体 + 外部函数”组织为具有封装边界的类与对象。
- **前置知识**：命名空间、函数、结构体、指针。
- **后续连接**：对象和 `this` 是构造析构、运算符重载、`const` 成员和模板类的基础。

### 核心主题与检索词

| 主题 | 常见检索词或用户问法 |
|---|---|
| 类定义 | `class`、成员变量、成员函数、类后分号、声明定义分离 |
| 访问控制 | `public`、`private`、`protected`、封装、class 和 struct |
| 类域 | `::`、成员函数类外定义、名字查找 |
| 实例化 | 类和对象区别、对象何时占空间、多个对象是否共享成员 |
| 对象大小 | `sizeof`、空类、内存对齐、成员函数是否在对象内 |
| `this` | 隐式形参、当前对象、能否修改 `this`、成员访问 |
| C/C++ 对比 | C 版 `Stack`、类封装、显式指针参数与隐式 `this` |

### 贯穿案例

- `Date`：私有年月日与公开初始化、打印接口。
- `Stack`：把数据和操作放入同一类型，调用从 `STPush(&s, x)` 过渡到 `s.Push(x)`。

### 高风险主题

- `COR-EMPTY-CLASS`：空类对象大小应表述为非零，常见实现为 1。
- `COR-OBJECT-LAYOUT`：对象大小与对齐受实现和 ABI 影响。
- `COR-NULL-THIS`：不能依赖空指针调用非静态成员函数。

## 03：类和对象（中）

- **资料**：`03.类和对象(中).pdf`
- **合并总结当前范围**：第 2339～4250 行
- **本章主线**：理解对象如何创建、销毁、复制、赋值和参与运算，是七章中的核心大章。
- **前置知识**：类、对象、`this`、引用、函数重载。
- **后续连接**：初始化列表细化构造；动态内存放大所有权问题；模板类要求复制语义对不同类型都成立。

### 核心主题与检索词

| 主题 | 常见检索词或用户问法 |
|---|---|
| 默认成员函数 | 编译器自动生成、六个默认成员函数、何时需要自己写 |
| 构造函数 | 默认构造、全缺省构造、自动调用、`Date d()`、初始化 |
| 析构函数 | 自动清理、析构顺序、RAII、提前返回会不会泄漏 |
| 拷贝构造 | `T(const T&)`、为什么传引用、逐成员复制、深浅拷贝 |
| 拷贝赋值 | `operator=`、自赋值、返回 `*this`、连续赋值 |
| 运算符重载 | 成员/非成员、前后置 `++`、不能重载的运算符、流运算符 |
| `const` 成员 | `this` 的 const、const 对象、只读接口、取地址重载 |
| 拷贝与传值 | 按值传参、按引用传参、按值返回、返回局部引用 |

### 贯穿案例

- `Date`：完整值类型，覆盖比较、日期加减、前后置自增、流运算符和 `const` 成员。
- `Stack`：拥有动态数组的资源类型，用于解释浅拷贝、深拷贝和重复释放。

### 高风险主题

- `COR-VEXING-PARSE`：`Date d();` 通常声明函数，不是定义对象。
- `COR-REF-LIFETIME`：返回局部对象引用会形成悬空引用。
- `COR-RESOURCE-COPY`：逐成员拷贝、所有权、深浅拷贝和重复释放。
- `COR-SPECIAL-MEMBERS`：Rule of Three 是设计信号，不是无条件语法命令。
- `COR-ELISION`：按值返回与拷贝省略受标准版本和场景影响。

- `Date`：初始化列表、转换构造、`explicit` 和临时对象。
- 对象计数器：静态成员变量与静态成员函数。

### 高风险主题

- `COR-INIT-ORDER`：成员初始化顺序只由声明顺序决定。
- `COR-VLA`：运行期长度原生数组不是标准 C++。
- `COR-STATIC-MEMBER`：静态成员定义规则存在标准版本差异。
- `COR-ELISION`：保证的拷贝省略与可选 NRVO 必须区分。

## 05：内存管理

- **资料**：`05.内存管理.pdf`
- **合并总结当前范围**：第 5832～6249 行
- **本章主线**：把对象生命周期与动态存储结合起来，区分“获得原始存储”和“构造对象”。
- **前置知识**：C 动态内存、构造析构、深浅拷贝。
- **后续连接**：类模板容器、STL 分配器、RAII 容器和智能资源管理。

### 核心主题与检索词

| 主题 | 常见检索词或用户问法 |
|---|---|
| 教学内存分区 | 栈、堆、静态区、代码段、字符串字面量、指针在哪里 |
| C 动态内存 | `malloc`、`calloc`、`realloc`、`free`、失败处理 |
| C++ 动态内存 | `new`、`delete`、`new[]`、`delete[]`、初始化 |
| 自定义类型 | new 是否调构造、delete 是否调析构、数组对象 |
| 分配函数 | `operator new`、`operator delete`、与 malloc/free 的关系 |
| 定位 new | placement new、原始存储、显式析构、内存池 |
| 方式比较 | 类型安全、失败模型、构造析构、配对关系 |

### 贯穿案例

- 动态创建和销毁 `Stack`、`Date` 或简单类对象。
- 用 placement new 区分分配存储与开始对象生命周期。

### 高风险主题

- `COR-MEMORY-MODEL`：栈、堆、数据段是常见实现模型，不是标准固定布局。
- `COR-REALLOC`：直接覆盖原指针会在失败时造成泄漏风险。
- `COR-ALLOC-PAIR`：申请和释放方式必须正确配对。
- `COR-NEW-FAILURE`：普通 throwing `new` 与 `std::nothrow` 的失败语义不同。
- `COR-PLACEMENT-NEW`：对齐、容量、构造成功和显式析构均需考虑。

## 06：模板初阶

- **资料**：`06.模板初阶.pdf`
- **合并总结当前范围**：第 6250～6810 行
- **本章主线**：把仅类型不同的重复代码抽象为由编译器实例化的泛型代码。
- **前置知识**：函数重载、引用、类、构造析构和动态内存。
- **后续连接**：STL 容器、迭代器、算法和仿函数都建立在模板机制上。

### 核心主题与检索词

| 主题 | 常见检索词或用户问法 |
|---|---|
| 泛型编程 | 重复重载、宏、类型安全、代码复用 |
| 函数模板 | `template<typename T>`、`class` 与 `typename`、`Swap<T>` |
| 实例化 | 隐式实例化、显式模板实参、编译器何时生成代码 |
| 模板推导 | `Add(1, 2.0)`、类型冲突、是否自动转换 |
| 重载决议 | 普通函数和模板谁优先、最佳匹配、显式选择模板 |
| 类模板 | `Stack<T>`、具体类型、成员函数类外定义 |
| 定义可见性 | 模板为什么通常放头文件、显式实例化 |

### 贯穿案例

- 将多套 `Swap`、`Add` 重载改写为函数模板。
- 将固定元素类型的 `Stack` 改写为 `Stack<T>`。

### 高风险主题

- `COR-TEMPLATE-DEDUCTION`：推导阶段通常不靠普通隐式转换解决冲突。
- `COR-TEMPLATE-OVERLOAD`：普通函数不是无条件优先，必须按最佳匹配分析。
- `COR-TEMPLATE-VISIBILITY`：模板定义通常需在实例化点可见，但并非绝对不能分离。

## 07：STL 简介

- **资料**：`07.STL简介.pdf`
- **合并总结当前范围**：第 6811～7282 行
- **本章主线**：理解 STL 的定位、六大组件和后续学习方法，不展开 08 以后具体容器细节。
- **前置知识**：类、对象生命周期、运算符重载、模板和动态内存。
- **后续连接**：`string`、`vector`、`list`、`stack`、`queue` 和模板进阶。

### 核心主题与检索词

| 主题 | 常见检索词或用户问法 |
|---|---|
| STL 定位 | Standard Template Library、标准库、是否等同于整个标准库 |
| STL 版本 | HP、P. J.、RW、SGI、源码学习 |
| 六大组件 | 容器、算法、迭代器、仿函数、适配器、空间配置器 |
| 组件协作 | 算法为什么接收迭代器、容器与算法解耦 |
| 容器适配器 | `stack`、`queue`、`priority_queue` |
| 学习层次 | 能用、明理、能扩展、接口/底层/扩展 |

### 贯穿案例

- 将手写 `Stack<T>` 与 `std::stack` 的定位进行概念对照。
- 用“两个栈实现队列”等问题说明标准组件组合能力。

### 高风险主题

- `COR-STL-SCOPE`：STL 是标准库的重要组成部分，但不等于整个标准库。
- `COR-CONTAINER-ADAPTER`：`stack`、`queue`、`priority_queue` 是容器适配器。
- `COR-SGI-STANDARD`：SGI STL 的实现经验不能替代标准行为。

## 跨章知识链

| 用户问题 | 优先定位 | 关系 |
|---|---|---|
| 为什么拷贝构造参数通常是 `const T&` | 01 → 03 | 引用避免按值递归，`const` 扩大可绑定对象范围并表达只读 |

| 为什么类中有裸指针时复制危险 | 02 → 03 → 05 | 封装不自动解决所有权；默认逐成员复制可能共享动态资源 |
| 初始化列表为什么重要 | 03 → 04 | 构造函数负责对象初始化，而初始化列表决定成员如何进入初始状态 |

| `Date` 的拷贝次数为什么不固定 | 03 → 04 | 先看语言语义，再区分标准版本、保证消除和可选 NRVO |
| 模板为什么是 STL 的基础 | 06 → 07 | 模板提供类型参数，STL 用其解耦容器、迭代器、算法和策略 |
