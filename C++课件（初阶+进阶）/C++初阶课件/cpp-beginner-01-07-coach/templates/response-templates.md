# 响应模板

## 使用规则

这些模板是可裁剪的最小骨架，不是每次都必须完整输出的固定表单。

1. 短问题优先短答；一句话能回答清楚时，不扩写成多个机械栏目。
2. 删除没有实际内容的栏目，不保留空标题。
3. 只使用与当前模式相关的模板，可组合但不要重复信息。
4. 自测和苏格拉底模式默认不出现答案区。
5. `依据` 只列本轮实际读取的材料；不得把占位文字或猜测页码留在最终回答中。
6. 课件与标准没有差异时，不强制输出“标准修正”四层结构。

## 快速复习模板

```markdown
# [章节或知识点] 快速复习

## 一句话主线
[用一句话串起本次复习内容]

## 必会结论
1. **[结论]**：[最小解释]
2. **[结论]**：[最小解释]

## 最容易错
- **[易错点]**：错误理解 → 正确理解
- **[易错点]**：适用条件或后果

## 最小代码/贯穿案例
[只有确实有助于复习时保留]

## 回忆检查
1. [不带答案的问题]
2. [不带答案的问题]

**依据**
[使用依据模板，只列实际读取内容]
```

三分钟模式可只保留“一句话主线、必会结论、最容易错、回忆检查”。

## 分层讲解模板

````markdown
## 结论
[直接回答用户问题]

## 为什么
[连接 C 语言、前置章节或用户已有经验]

## 机制
[解释编译期规则、对象生命周期、重载过程或资源所有权]

## 最小例子
```cpp
// 必要且尽量可编译的示例
```

## 边界与易错
- [标准版本、临时对象、编译器扩展或常见误解]

## 理解检查
[一道不立即附答案的短问题]

**依据**
[使用依据模板]
````

简单定义题可只保留“结论 + 为什么/机制”。

## 自测出题模板

```markdown
**范围**：[章节或知识点]  
**进度**：第 [N] 题 / 共 [M] 题（题数确定时才写）

### 第 [N] 题｜[题型或难度]

[题目正文]

**作答要求**：[要求给结论、理由、代码或边界条件]
```

默认到此停止并等待用户作答。不要附参考答案、评分点或提示，除非用户明确要求。

## 苏格拉底模板

```markdown
**当前已知**：[简短确认用户已经得到的事实]

**关键问题**：[每轮只问一个推动推理的问题]

<details>
<summary>需要时展开一个提示</summary>

[只给当前层级的关键词或半成品框架，不给完整答案]

</details>
```

如果终端或使用环境不适合折叠块，改为：

```markdown
**提示（需要时再看）**：[一个最弱可用提示]
```

## 批改模板

```markdown
## 判定
[正确 / 基本正确 / 部分正确 / 错误]：[一句话总评]

## 你答对的部分
- [保留用户已经理解的内容]

## 缺失或错误
- **[问题]**：[为什么不完整或不正确]

## 错因
[概念混淆 / 条件遗漏 / 把实现当标准 / 生命周期遗漏 / 所有权遗漏 / 其他]

## 推荐答案
[尽量保留用户原表达风格的准确版本]

## 针对性追问
[一道针对当前错因的变式题，默认不附答案]

**依据**
[使用依据模板]
```

完全正确时可省略“缺失或错误”和“错因”，改为指出可进一步提升的边界条件。

## 代码分析模板

```markdown
## 结论
[能否编译；若能编译，行为是否定义良好；是否存在确定输出]

## 标准假设
- 标准版本：[如 C++11 / C++17]
- 编译器扩展：[没有则删除]
- 必要上下文：[没有则删除]

## 编译性
[语法、名称查找、重载决议或模板推导结论]

## 行为分类
[定义良好 / 逻辑错误 / 实现定义 / 未指定 / 未定义行为 / 编译器扩展]

## 生命周期与所有权
1. [对象何时构造或引用何时绑定]
2. [复制、赋值、资源转移或销毁过程]

## 执行过程或结果
[只有行为定义良好时才推导唯一输出]
```

存在未定义行为时，用下面文字替代固定输出：

```markdown
程序不具有标准保证的唯一输出，因此不继续推导固定结果。某次运行表现只能作为特定编译器和选项下的现象。
```

然后继续：

````markdown
## 最小修正
```cpp
// 只修复当前问题的最小改法
```

**依据**
[使用依据模板]
````

## 标准修正模板

仅在课件存在简化、歧义、版本差异或事实问题时使用：

```markdown
### 标准结论
[标准意义下应如何理解]

### 课件表述
[课件如何说，以及它的教学意图]

### 差异类型
[教学简化 / 标准版本差异 / 编译器扩展 / 事实错误]

### 学习建议
- **当前课程或考试**：[怎样理解和作答]
- **实际编码**：[怎样安全处理]
- **后续深入**：[需要补充的主题；没有则删除]
```

不要只写“课件错了”，也不要为了贴合课件隐藏标准问题。

## 依据模板

### 已实际读取 PDF 和总结

```markdown
**依据**
- 课件：`[实际文件名].pdf`，PDF 第 [实际读取页码] 页
- 复习结构：`01到07复习总结合并版.md` → “[实际读取标题]”
- 标准修正：[实际涉及的主题；没有则删除]
```

执行时必须把方括号内容替换为真实信息；不能确认的项直接删除。

### 只读取合并总结（仅限 PDF 缺失或无法解析时降级）

```markdown
**依据**
- 复习结构：`01到07复习总结合并版.md` → “[实际读取标题]”
- 当前因 PDF [缺失 / 无法解析]，按合并总结降级组织，尚未核对原课件。
```

PDF 可读取时，事实性结论不得使用此模板来绕过原页核对。

### 只核对 PDF

```markdown
**依据**
- 课件：`[实际文件名].pdf`，PDF 第 [实际读取页码] 页
```

### 标准修正或课件外补充

```markdown
**依据**
- 课件：`[实际读取材料；未读取则删除]`
- 标准修正：[修正主题]
- 课件外补充：[补充主题；没有则删除]
```

### 禁止形式

最终回答中不得出现：

- `第 X～Y 页` 之类未替换占位符；
- 没有实际打开过的 PDF 页码；
- “老师重点强调”但材料中无法确认的说法；
- 只由 `chapter-index.md` 推测出的课件原文；
- 把标准补充写成课件内容。
