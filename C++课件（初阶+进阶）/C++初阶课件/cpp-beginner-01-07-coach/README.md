# C++ 初阶 01～07 复习教练使用说明

## 一、这是什么？

`cpp-beginner-01-07-coach` 是一份基于固定课程资料构建的 **C++ 初阶专用复习教练 Skill**。

它围绕 01～07 七份 C++ 初阶 PDF 课件和已有复习总结，为已经学过这些内容的学习者提供：

- 快速恢复知识结构；
- 深入理解语言机制；
- 逐题检测掌握程度；
- 通过提示自行推导答案；
- 批改解释、答案和代码；
- 分析课程范围内的 C++ 程序；
- 区分课件教学口径与更准确的标准 C++ 结论。

一句话概括：

> 它是“固定课件驱动的 C++ 初阶复习教练”，不是普通 C++ 百科，也不是接收任意 PDF 自动生成总结的工具。

---

## 二、它使用哪些资料？

技能默认使用同级课件目录中的以下资料：

1. `01.C++入门基础.pdf`
2. `02.类和对象(上).pdf`
3. `03.类和对象(中).pdf`
4. `04.类和对象(下).pdf`
5. `05.内存管理.pdf`
6. `06.模板初阶.pdf`
7. `07.STL简介.pdf`
8. `01到07复习总结合并版.md`

这些资料的职责不同：

| 资料 | 主要作用 |
|---|---|
| 01～07 PDF | 核对课程事实、课件例子、教学顺序和课件口径 |
| 合并复习总结 | 组织知识结构、易错点、一页纸内容、用户注释和二刷重点 |
| `references/chapter-index.md` | 定位章节、关键词、跨章关系和高风险主题 |
| `references/correctness-policy.md` | 校准 C++ 标准规则，处理课件简化、歧义或错误 |
| `profiles/learning-modes.md` | 规定六种学习模式的执行方式 |
| `templates/response-templates.md` | 提供可裁剪的回答骨架 |

### 来源原则

- **PDF 是课程事实与教学边界的主依据。**
- 合并总结用于组织复习，不高于 PDF。
- 章节索引只负责定位，不能证明课件事实。
- 事实性结论和课件引用必须读取对应 PDF 页面。
- 只有 PDF 缺失或无法解析时，才能按总结降级，并且必须明确说明。
- 只能引用本轮实际读取的 PDF 页码，禁止猜测。

## 三、适合什么人？

默认适合：

- 已学过 C 语言和基础数据结构；
- 已经学习过这套 C++ 初阶 01～07 课程；
- 希望通过二刷、讲解、测试和纠错巩固知识；
- 不满足于只背结论，希望理解 C++ 语言机制；
- 需要识别课件教学简化与标准规则差异。

它不会默认把使用者当作编程零基础，但也不会把“学过”直接等同于“已经掌握”。

## 四、六种核心功能

## 1. 快速复习

### 适合场景

- 考前恢复知识结构；
- 学完一章后进行二刷；
- 用三分钟或十分钟回顾重点；
- 生成高密度的一页纸复习内容。

### 典型输出

- 一句话知识主线；
- 必须掌握的核心结论；
- 最容易混淆的知识点；
- 必要的贯穿案例；
- 不带答案的回忆问题。

### 使用示例

```text
按这套 C++ 初阶 01～07 课件，三分钟复习引用。
```

```text
根据这套课件，给我一份“类和对象（中）”的十分钟复习。
```

```text
把 05 内存管理整理成一页纸复习版，重点突出易错点。
```

## 2. 分层讲解

### 适合场景

- 不理解某个概念为什么这样设计；
- 想从 C 语言经验迁移到 C++；
- 想理解对象生命周期、重载、模板推导等机制；
- 需要区分课件表述和标准结论。

### 默认讲解顺序

1. 先给结论；
2. 连接 C 语言或前置知识；
3. 解释语言机制；
4. 给最小代码示例；
5. 说明边界和易错点；
6. 给一道理解检查题。

### 使用示例

```text
根据这套课件，讲清楚为什么拷贝构造函数的参数通常写成 const T&。
```

```text
从 C 语言指针的角度解释 C++ 引用，但不要按零基础讲。
```

```text
按课件和标准 C++ 分别解释 new 与 operator new 的区别。
```

## 3. 逐题自测

### 适合场景

- 检测自己是否真正掌握；
- 复习后主动回忆；
- 训练编译判断、生命周期分析和代码改错；
- 查找薄弱章节。

### 默认行为

- 每轮只出一道题；
- 不提前给答案和评分点；
- 用户回答后再批改；
- 答对后追问边界或变式；
- 答错后解释错因，再换角度复测。

### 可用题型

- 概念判断；
- 编译性判断；
- 重载选择；
- 生命周期分析；
- 代码输出分析；
- 代码改错；
- 跨章迁移；
- 小型手写代码题。

### 使用示例

```text
按这套课件逐题考我拷贝构造，不要提前给答案。
```

```text
检测我对初始化列表的掌握程度，每次只出一道题。
```

```text
从 01～07 中混合出题，重点考生命周期、内存管理和模板推导。
```

## 4. 苏格拉底提问

### 适合场景

- 不想直接查看答案；
- 希望自己推导出错误原因；
- 解决浅拷贝、初始化顺序、生命周期、模板匹配等推理问题；
- 做代码题时卡住，需要逐步提示。

### 提示方式

技能默认每轮只问一个关键问题，并按以下层级逐渐增强提示：

1. 重述现象；
2. 给出关键词；
3. 给出半成品推理框架；
4. 给出局部结论；
5. 用户明确要求或连续卡住后，再给完整解释。

### 使用示例

```text
不要直接给答案，一步步引导我发现这个 Stack 为什么会发生浅拷贝。
```

```text
用苏格拉底提问带我分析这段代码的成员初始化顺序。
```

```text
我不理解 Add(1, 2.0) 为什么模板推导失败，先提示我，不要直接讲完。
```

## 5. 批改纠错

### 适合场景

- 批改自己的概念解释；
- 检查自测答案；
- 修改适合考试或口述的回答；
- 找出“结论对但理由不完整”的问题。

### 批改内容

技能不会只说“对”或“错”，而会区分：

- 正确部分；
- 遗漏部分；
- 错误部分；
- 错因类型；
- 推荐答案；
- 针对性变式题。

常见错因包括：

- 概念混淆；
- 条件遗漏；
- 生命周期遗漏；
- 所有权遗漏；
- 把常见实现当成标准保证；
- 把编译通过当成代码正确；
- 只记住结论，没有理解机制；
- 混淆课件口径与标准口径。

### 使用示例

```text
这是我对拷贝构造和赋值重载区别的解释，请按这套课件批改：……
```

```text
我认为普通函数一定比模板优先。请指出我的说法哪里不准确。
```

```text
请按课件和标准 C++ 两个层次批改我对 new 失败处理的回答。
```

## 6. 代码分析

### 适合场景

分析 01～07 范围内的代码，例如：

- 能否编译；
- 调用哪个重载；
- 是否有确定输出；
- 构造、拷贝、赋值和析构顺序；
- 引用是否悬空；
- 是否发生浅拷贝；
- `new/delete` 是否匹配；
- 模板推导是否成功；
- 是否存在未定义行为。

### 固定分析顺序

1. 明确 C++ 标准版本和必要假设；
2. 判断能否通过编译；
3. 判断行为类别；
4. 跟踪对象生命周期；
5. 分析资源所有权；
6. 只有行为定义良好时才推导唯一输出；
7. 给出最小修正。

如果程序存在未定义行为，技能会明确说明：

> 程序不具有标准保证的唯一输出，因此不能继续推导固定结果。

### 使用示例

```text
根据这套课件分析下面代码能否编译、是否存在未定义行为，并给出最小修正：
[粘贴代码]
```

```text
按 C++11 分析这段 Date 代码的构造、拷贝和析构顺序。
```

```text
分析这个 Stack 拷贝为什么会重复释放，不要重写整个类，只给最小修正。
```

## 五、推荐使用方式

## 方式一：复习闭环

建议按以下顺序使用：

```text
快速复习 → 逐题自测 → 批改纠错 → 变式重测
```

示例：

```text
先给我十分钟复习“类和对象（中）”，然后逐题考我。
```

完成复习后可以继续：

```text
开始自测，每轮只出一道题，不要提前给答案。
```

---

## 方式二：难点理解闭环

```text
分层讲解 → 苏格拉底推导 → 最小代码验证 → 变式问题
```

示例：

```text
先讲清楚初始化顺序的规则，再用苏格拉底提问让我分析一道代码题。
```

---

## 方式三：代码查错闭环

```text
代码分析 → 错因定位 → 最小修正 → 同类变式
```

示例：

```text
先判断这段代码是否有未定义行为，再解释错因，最后给我一道同类型变式题。
```

## 六、怎样提问效果更好？

建议在提示中尽量包含以下信息：

1. **资料范围**：说明按本套 01～07 课件；
2. **章节或知识点**：例如引用、拷贝构造、内存管理；
3. **使用模式**：复习、讲解、自测、引导、批改或代码分析；
4. **期望深度**：三分钟、十分钟、机制级、考试口述等；
5. **交互要求**：是否逐题、是否隐藏答案、是否只给提示；
6. **标准版本**：代码行为受版本影响时说明 C++11、C++17 等。

### 推荐提示词模板

```text
请按 C++ 初阶 01～07 课件，对【章节/知识点】进行【模式】。

要求：
- 深度：【快速复习 / 机制级讲解 / 考试口述】
- 交互：【逐题进行 / 不提前给答案 / 每轮只提示一步】
- 标准版本：【C++11 / C++17 / 未指定】
- 重点关注：【生命周期 / 所有权 / 易错点 / 代码行为】
```

### 示例

```text
请按 C++ 初阶 01～07 课件，对“拷贝构造和赋值重载”进行分层讲解。

要求：
- 深度：机制级讲解；
- 标准版本：C++11；
- 重点关注：调用场景、参数形式、返回值、浅拷贝和自赋值；
- 最后给一道不带答案的代码判断题。
```

## 七、课件与标准 C++ 冲突时怎样处理？

技能不会盲目照搬课件，也不会简单说“课件错了”。

遇到教学简化、版本差异、编译器扩展或事实问题时，按以下结构处理：

```text
标准结论
→ 课件表述
→ 差异类型
→ 当前课程与实际编码建议
```

重点校准的主题包括：

- 空指针调用非静态成员函数；
- 空类对象大小；
- 返回局部对象引用；
- 引用与临时对象生命周期；
- 浅拷贝和重复释放；
- 初始化列表与成员声明顺序；
- 非标准 VLA；
- throwing `new` 与 `std::nothrow`；
- `new` 与 `operator new`；
- 模板推导与隐式转换；
- 普通函数和模板的重载决议；
- 拷贝省略、RVO、NRVO 与标准版本；
- STL 与整个 C++ 标准库的范围区别。

## 八、当前不支持什么？

## 1. 不接收任意 PDF 自动生成完整总结

当前技能不是通用的：

```text
指定任意 PDF → 生成完整复习总结
```

生成类似 `01到07改进版.md` 的长篇复习资料，需要另行增加“复习总结生成模式”和端到端质量测试。

## 2. 不默认覆盖 08～12

以下内容属于后续课件，不是当前技能的直接资料范围：

- `string` 详细接口；
- `vector`；
- `list`；
- `stack` 和 `queue` 的具体接口与实现；
- 模板进阶。

07 只负责 STL 的定位、六大组件和学习方法概览。

## 3. 不负责大型 C++ 工程任务

例如：

- CMake 构建修复；
- 大型项目重构；
- 服务端工程代码审查；
- 完整功能实现；
- 大规模性能优化。

## 4. 不负责课件外高级主题

例如：

- C++20 协程；
- 并发编程；
- Concepts；
- 模板元编程；
- 完整智能指针体系；
- 高级 STL 源码专题。

如确需补充，必须明确标为“课件外补充”，不能伪装成 01～07 已讲内容。
