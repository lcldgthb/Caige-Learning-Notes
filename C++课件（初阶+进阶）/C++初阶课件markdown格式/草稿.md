这是 C++ 运算符重载里面最经典、也是最重要的一个知识点。你现在学到类和运算符重载，这个知识点以后几乎每个类都会用到。

先看最普通的写法：

```cpp
cout << 10;
```

实际上编译器会把它理解成：

```cpp
operator<<(cout, 10);
```

也就是：

```cpp
<<(cout, 10);
```

所以：

```cpp
a + b
```

本质上是：

```cpp
operator+(a, b);
```

而：

```cpp
cout << x
```

本质上是：

```cpp
operator<<(cout, x);
```

---

## 一、如果写成成员函数会发生什么？

假设：

```cpp
class Date
{
public:
    void operator<<(ostream& out)
    {
        out << _year << "-" << _month << "-" << _day;
    }

private:
    int _year = 2026;
    int _month = 7;
    int _day = 13;
};
```

那么：

```cpp
Date d;
d << cout;
```

实际上会变成：

```cpp
d.operator<<(cout);
```

注意：

```text
左操作数永远是 this
右操作数才是参数
```

也就是说：

```cpp
d << cout
```

对应：

```cpp
d.operator<<(cout)
```

而：

```cpp
cout << d
```

对应：

```cpp
cout.operator<<(d)
```

问题来了：

```text
cout 属于 ostream 类，
不是 Date 类。
```

因此：

```cpp
cout.operator<<(d)
```

调用的是 `ostream` 自己的 `operator<<`，根本不会调用你的 `Date::operator<<()`。

---

## 二、所以必须写成全局函数

正确写法：

```cpp
class Date
{
public:
    Date(int y=1,int m=1,int d=1)
        : _year(y), _month(m), _day(d)
    {}

private:
    int _year;
    int _month;
    int _day;

    friend ostream& operator<<(ostream& out,const Date& d);
};
```

然后：

```cpp
ostream& operator<<(ostream& out,const Date& d)
{
    out << d._year << "-"
        << d._month << "-"
        << d._day;

    return out;
}
```

这样：

```cpp
Date d(2026,7,13);

cout << d;
```

编译器会转换成：

```cpp
operator<<(cout, d);
```

参数对应：

```text
out -> cout
d   -> Date对象
```

于是输出：

```text
2026-7-13
```

---

## 三、为什么返回 ostream& ?

如果不返回：

```cpp
void operator<<(ostream& out,const Date& d)
{
    ...
}
```

那么：

```cpp
cout << d << endl;
```

就变成：

```cpp
(operator<<(cout,d)) << endl;
```

但是：

```cpp
operator<<(cout,d)
```

返回的是：

```cpp
void
```

于是：

```cpp
void << endl
```

显然不合法。

---

因此：

```cpp
ostream& operator<<(ostream& out,const Date& d)
{
    out << d._year << "-"
        << d._month << "-"
        << d._day;

    return out;
}
```

返回：

```cpp
out
```

于是：

```cpp
cout << d << endl;
```

实际上变成：

```cpp
(operator<<(cout,d)) << endl
```

↓

```cpp
cout << endl
```

所以链式调用成立。

---

## 四、`>>` 同理

例如：

```cpp
istream& operator>>(istream& in,Date& d)
{
    in >> d._year
       >> d._month
       >> d._day;

    return in;
}
```

于是：

```cpp
cin >> d;
```

变成：

```cpp
operator>>(cin,d);
```

而：

```cpp
cin >> d1 >> d2;
```

变成：

```cpp
(operator>>(cin,d1)) >> d2;
```

↓

```cpp
cin >> d2;
```

因此能够连续输入。

## 五、完整代码示例

```cpp
#include <iostream>
using namespace std;

class Date
{
    friend ostream& operator<<(ostream& out,const Date& d);
    friend istream& operator>>(istream& in,Date& d);

public:
    Date(int y=1,int m=1,int d=1)
        :_year(y),_month(m),_day(d)
    {}

private:
    int _year;
    int _month;
    int _day;
};

ostream& operator<<(ostream& out,const Date& d)
{
    out << d._year << "-"
        << d._month << "-"
        << d._day;

    return out;
}

istream& operator>>(istream& in,Date& d)
{
    in >> d._year
       >> d._month
       >> d._day;

    return in;
}

int main()
{
    Date d;

    cin >> d;
    cout << d << endl;

    return 0;
}
```

输入：

```text
2026 7 13
```

输出：

```text
2026-7-13
```

最后记一句考试必背结论：

| 运算符              | 通常重载方式       |
| ---------------- | ------------ |
| `+ - * / == < >` | 成员函数或全局函数都可以 |
| `=`              | 必须成员函数       |
| `[]`             | 必须成员函数       |
| `()`             | 必须成员函数       |
| `->`             | 必须成员函数       |
| `<< >>`          | 通常重载为全局函数    |

原因：

> `cout` 和 `cin` 是左操作数，不是你的类对象，因此 `<<` 和 `>>` 一般写成全局函数，并返回流对象引用以支持链式调用。


表面上看：

> “多拷贝一次就多拷贝一次呗，有什么关系？”

对于只有几个 `int` 的类来说，确实影响不大。但对于真正的 C++ 类来说，这个问题可能非常严重，甚至会导致程序无法工作。

先看你的 `Date`：

```cpp
class Date
{
private:
    int _year;
    int _month;
    int _day;
};
```

如果这样写：

```cpp
Date& operator=(Date d)
{
    _year = d._year;
    _month = d._month;
    _day = d._day;

    return *this;
}
```

调用：

```cpp
Date d1;
Date d2;

d1 = d2;
```

实际上发生的是：

```text
① 用 d2 拷贝构造一个临时对象 d
② 用 d 给 d1 赋值
③ 临时对象 d 销毁
```

也就是：

```text
d2
 ↓ 拷贝构造
临时对象 d
 ↓ 赋值
d1
```

而如果写：

```cpp
Date& operator=(const Date& d)
```

则变成：

```text
d2
 ↓
引用 d
 ↓
d1
```

没有任何额外对象产生。

## 用代码看得更明显

```cpp
class Date
{
public:
    Date()
    {
        cout << "构造" << endl;
    }

    Date(const Date&)
    {
        cout << "拷贝构造" << endl;
    }

    Date& operator=(Date d)
    {
        cout << "赋值运算符" << endl;
        return *this;
    }
};
```

执行：

```cpp
Date d1;
Date d2;

d1 = d2;
```

输出：

```text
构造
构造
拷贝构造
赋值运算符
```

你会发现：

```text
居然多调用了一次拷贝构造！
```

---

改成：

```cpp
Date& operator=(const Date& d)
{
    cout << "赋值运算符" << endl;
    return *this;
}
```

输出：

```text
构造
构造
赋值运算符
```

没有多余操作。

## 更严重的问题：可能无限递归

假设：

```cpp
class Date
{
public:
    Date(const Date& d)
    {
        *this = d;
    }

    Date& operator=(Date d)
    {
        return *this;
    }
};
```

执行：

```cpp
Date d1;
Date d2;

d1 = d2;
```

过程：

```text
operator=(d2)

为了构造参数 d
↓
调用拷贝构造

拷贝构造里面
↓
又调用 operator=

operator= 又需要构造参数 d
↓
再次调用拷贝构造
```

于是：

```text
拷贝构造
↓
operator=
↓
拷贝构造
↓
operator=
↓
拷贝构造
...
```

最终：

```text
栈溢出（Stack Overflow）
```

虽然正常代码一般不会这么写，但说明：

> `operator=(Date d)` 在设计上本身就存在隐患。

## 真正的大问题：资源类

例如：

```cpp
class String
{
private:
    char* _str;
};
```

假设字符串长度：

```text
100MB
```

执行：

```cpp
s1 = s2;
```

如果参数是：

```cpp
String d
```

那么：

```text
先复制100MB字符串
再执行赋值
然后销毁临时对象
```

等于：

```text
100MB复制 + 100MB释放 + 真正赋值
```

而：

```cpp
const String&
```

只传递一个地址：

```text
8字节
```

性能差距非常大。

---

## 那为什么还要加 const？

因为：

```cpp
Date& operator=(Date& d)
```

会导致：

```cpp
d1 = d2;
```

可以。

但：

```cpp
d1 = Date();
```

不行。

因为：

```cpp
Date()
```

是临时对象。

临时对象只能绑定：

```cpp
const Date&
```

不能绑定：

```cpp
Date&
```

所以标准写法必须是：

```cpp
Date& operator=(const Date& d)
```

这样：

```cpp
d1 = d2;
d1 = Date();
d1 = func();
```

都能正常工作。

---

因此标准答案其实是三句话：

```text
1. 引用避免额外拷贝，提高效率。
2. const 保证不会修改右操作数。
3. const 引用可以接收临时对象。
```

所以几乎所有接受“输入参数”的地方，C++ 都喜欢写：

```cpp
const T&
```

例如：

```cpp
void func(const string& s);
bool operator<(const Date& d) const;
Date(const Date& d);
Date& operator=(const Date& d);
```

这是现代 C++ 最常见、最重要的参数传递方式之一。
