## 一、本讲核心主线

这一讲主要是 STL 的入门介绍，重点不是具体使用细节，而是建立整体框架：

1. STL 是什么
2. STL 有哪些版本
3. STL 的六大组件
4. STL 为什么重要
5. STL 应该怎么学

一句话概括：

> STL 是 C++ 标准库的重要组成部分，它把常用数据结构和算法做成了可复用的软件框架，让我们不用重复造轮子。

---

## 二、什么是 STL

STL 全称：

```text
Standard Template Library
标准模板库
```

它是 C++ 标准库的重要组成部分。

STL 不只是一个简单的组件库，而是：

> 包含数据结构与算法的软件框架。

它提供了大量通用组件，例如：

- 顺序表 / 动态数组：`vector`
- 链表：`list`
- 栈：`stack`
- 队列：`queue`
- 优先级队列：`priority_queue`
- 集合：`set`
- 映射：`map`
- 哈希表相关容器：`unordered_map`、`unordered_set`
- 通用算法：排序、查找、遍历等

---

## 三、STL 的版本

课件中介绍了几个 STL 版本，复习时不需要死背细节，但要知道 SGI 版本比较重要。

---

### 1. 原始版本 / HP 版本

由：

- Alexander Stepanov
- Meng Lee

在惠普实验室完成。

特点：

- STL 的原始版本。
- 具有开源精神。
- 是所有 STL 实现版本的始祖。

---

### 2. P. J. 版本

由 P. J. Plauger 开发。

特点：

- 继承自 HP 版本。
- 被 Windows Visual C++ 采用。
- 不能公开或修改。
- 可读性较低，符号命名较怪。

---

### 3. RW 版本

由 Rouge Wage 公司开发。

特点：

- 继承自 HP 版本。
- 被 C++ Builder 采用。
- 不能公开或修改。
- 可读性一般。

---

### 4. SGI 版本

由 Silicon Graphics Computer Systems 公司开发。

特点：

- 继承自 HP 版本。
- 被 GCC / Linux 采用。
- 可移植性好。
- 可以公开、修改甚至贩卖。
- 命名风格和编程风格可读性较高。

复习重点：

> 后续学习 STL 源码时，主要参考 SGI 版本。

---

## 四、STL 的六大组件

STL 通常分为六大组件：

| 组件 | 作用 |
|---|---|
| 容器 | 存储数据的数据结构 |
| 算法 | 操作数据的通用算法 |
| 迭代器 | 连接容器和算法，类似泛化指针 |
| 仿函数 | 像函数一样使用的对象 |
| 适配器 | 对已有组件进行包装转换 |
| 空间配置器 | 负责内存申请和释放 |

---

### 1. 容器

容器用于存储数据。

常见容器：

```cpp
vector
list
deque
stack
queue
priority_queue
set
map
unordered_set
unordered_map
```

可以把容器理解为：

> STL 中封装好的常用数据结构。

---

### 2. 算法

算法用于操作容器中的数据。

例如：

```cpp
sort
find
count
reverse
lower_bound
upper_bound
```

算法通常不直接依赖某一种容器，而是通过迭代器操作数据。

---

### 3. 迭代器

迭代器是 STL 中非常核心的概念。

作用：

> 连接容器和算法。

可以把迭代器先粗略理解为：

> 类似指针的东西，用来访问容器中的元素。

例如：

```cpp
vector<int> v;
vector<int>::iterator it = v.begin();
```

后面学习 STL 时，迭代器是重点。

---

### 4. 仿函数

仿函数是像函数一样使用的对象。

本质通常是重载了 `operator()` 的类对象。

例如后续可能看到：

```cpp
greater<int>()
less<int>()
```

当前阶段了解即可。

---

### 5. 适配器

适配器是对已有组件做包装，让它表现出另一种使用形式。

典型例子：

```cpp
stack
queue
priority_queue
```

它们底层通常依赖已有容器实现，但对外提供特定接口。

例如：

- `stack` 提供栈接口。
- `queue` 提供队列接口。
- `priority_queue` 提供堆 / 优先级队列接口。

---

### 6. 空间配置器

空间配置器负责内存管理。

它是 STL 底层组件，主要负责：

- 空间申请
- 空间释放
- 对象构造
- 对象析构

当前阶段知道它是 STL 的底层内存管理组件即可。

## 五、STL 的重要性

### 1. 笔试中常见

课件提到的笔试题：

- 二叉树层序打印
- 重建二叉树
- 两个栈实现一个队列

这些题虽然是数据结构题，但如果熟悉 STL，可以更快写出代码。

例如：

- 层序遍历常用 `queue`。
- 两个栈实现队列可以用 `stack`。
- 查找映射关系可能用 `map` / `unordered_map`。

---

### 2. 面试中常见

面试中 STL 常考：

- 容器使用场景
- `vector` 扩容机制
- `list` 和 `vector` 区别
- `map` 和 `unordered_map` 区别
- 迭代器失效
- 常见算法复杂度
- 底层数据结构

这一讲只是简介，后续学习每个容器时要重点掌握底层原理。

---

### 3. 工作中重要

课件中提到一句话：

> 不懂 STL，不要说你会 C++。

原因：

- STL 提供大量成熟数据结构和算法。
- 能避免重复造轮子。
- 能显著提高开发效率。
- 很多工程代码都会大量使用 STL。

---

## 六、如何学习 STL

课件总结：

```text
能用，明理，能扩展
```

这三个层次非常重要。

---

### 第一层：能用

目标：

> 会查文档，会使用常见容器和算法解决问题。

例如：

- 会用 `vector` 存数组。
- 会用 `stack` 模拟栈。
- 会用 `queue` 做 BFS。
- 会用 `map` 统计映射关系。
- 会用 `sort` 排序。

这是刷题和项目的基础。

---

### 第二层：明理

目标：

> 理解 STL 容器和算法的底层原理。

例如：

- `vector` 底层是动态数组。
- `list` 底层是链表。
- `map` 底层通常是红黑树。
- `unordered_map` 底层是哈希表。
- `stack` / `queue` 是容器适配器。
- 迭代器失效为什么会发生。

这是面试和深入 C++ 的关键。

---

### 第三层：能扩展

目标：

> 能根据 STL 的思想设计自己的组件，甚至阅读和改造部分源码。

例如：

- 自己实现简单 `vector`。
- 自己实现迭代器。
- 理解空间配置器思想。
- 理解算法和容器如何通过迭代器解耦。

这是进阶方向。

---

## 七、STL 学习建议

结合你已经学过 C++ 类和对象、模板初阶，接下来学习 STL 时建议这样抓重点：

### 1. 先会用

先掌握常见容器基本接口：

```cpp
push_back
pop_back
push
pop
insert
erase
find
size
empty
begin
end
```

不要一开始就陷入源码细节。

---

### 2. 再理解底层结构

每学一个容器，都问：

1. 底层是什么数据结构？
2. 插入删除复杂度是多少？
3. 查找复杂度是多少？
4. 什么时候迭代器会失效？
5. 适合什么场景？

---

### 3. 最后做对比

STL 很多容器要通过对比来记：

| 对比 | 重点 |
|---|---|
| `vector` vs `list` | 连续空间 vs 链式空间 |
| `map` vs `unordered_map` | 红黑树 vs 哈希表 |
| `set` vs `map` | 只存 key vs 存 key-value |
| `stack` vs `queue` | 后进先出 vs 先进先出 |
| `deque` vs `vector` | 分段连续 vs 完全连续 |

---

## 八、易错点汇总

1. STL 不只是容器，还包括算法、迭代器、仿函数、适配器、空间配置器。
2. STL 是标准库的重要组成部分，不是某一个单独容器。
3. `stack`、`queue`、`priority_queue` 更准确地说是容器适配器。
4. 学 STL 不能只停留在会调接口，面试还要理解底层原理。
5. 迭代器是连接容器和算法的核心，后续要重点掌握。
6. SGI STL 版本可读性较高，后续源码学习主要参考它。
