# C/C++ 内存管理复习总结

> 来源：`05.内存管理.pdf`  
> 定位：已学一遍后的复习笔记，重点用于快速回忆内存分布、动态内存管理、`new/delete` 原理和面试高频区别。

---

## 一、本讲核心主线

这一讲主要解决三个问题：

1. C/C++ 程序中的变量分别存在哪里？
2. C 和 C++ 分别如何动态申请和释放堆空间？
3. `malloc/free` 和 `new/delete` 到底有什么区别？

一句话概括：

> `malloc/free` 只负责堆空间申请和释放；`new/delete` 除了申请和释放空间，还会对自定义类型自动调用构造函数和析构函数。

---

## 二、C/C++ 内存分布

常见内存区域：

| 区域 | 存放内容 |
|---|---|
| 栈 | 非静态局部变量、函数参数、返回值等 |
| 堆 | 程序运行时动态申请的空间 |
| 数据段 / 静态区 | 全局变量、静态变量 |
| 代码段 / 常量区 | 可执行代码、只读常量、字符串常量 |
| 内存映射段 | 动态库映射、共享内存等，了解即可 |

---

## 三、典型变量位置判断

示例：

```cpp
int globalVar = 1;
static int staticGlobalVar = 1;

void Test()
{
    static int staticVar = 1;
    int localVar = 1;
    int num1[10] = { 1, 2, 3, 4 };
    char char2[] = "abcd";
    const char* pChar3 = "abcd";
    int* ptr1 = (int*)malloc(sizeof(int) * 4);
}
```

重点结论：

| 名称 | 所在区域 | 原因 |
|---|---|---|
| `globalVar` | 数据段 / 静态区 | 全局变量 |
| `staticGlobalVar` | 数据段 / 静态区 | 静态全局变量 |
| `staticVar` | 数据段 / 静态区 | 静态局部变量 |
| `localVar` | 栈 | 普通局部变量 |
| `num1` | 栈 | 局部数组整体在栈上 |
| `char2` | 栈 | 局部字符数组整体在栈上 |
| `*char2` | 栈 | 数组元素在数组内部 |
| `pChar3` | 栈 | 局部指针变量本身在栈上 |
| `*pChar3` | 代码段 / 常量区 | 指向字符串常量 |
| `ptr1` | 栈 | 局部指针变量本身在栈上 |
| `*ptr1` | 堆 | `malloc` 申请的空间 |

最容易错的是：

```cpp
char char2[] = "abcd";      // 字符数组，内容拷贝到栈上
const char* pChar3 = "abcd"; // 指针在栈上，字符串常量在常量区
```

## 四、C 语言动态内存管理

C 语言中常用：

```cpp
malloc
calloc
realloc
free
```

### 1. `malloc`

```cpp
int* p = (int*)malloc(sizeof(int) * 4);
```

特点：

- 在堆上申请指定字节数的空间。
- 不初始化申请到的空间。
- 返回 `void*`，C++ 中需要强转。
- 申请失败返回 `NULL`。

---

### 2. `calloc`

```cpp
int* p = (int*)calloc(4, sizeof(int));
```

特点：

- 申请 `4` 个 `int` 大小的空间。
- 会把空间初始化为 `0`。

---

### 3. `realloc`

```cpp
int* p2 = (int*)realloc(p1, sizeof(int) * 10);
```

特点：

- 调整原动态内存块大小。
- 可能原地扩容，也可能重新开空间并拷贝旧数据。
- 返回新地址。

注意：

```cpp
int* p3 = (int*)realloc(p2, sizeof(int) * 10);
free(p3);
```

这里不需要再 `free(p2)`，因为 `realloc` 成功后应以返回的新指针为准。

---

### 4. `free`

```cpp
free(p);
```

特点：

- 释放堆空间。
- 只释放空间，不会调用析构函数。

---

## 五、C++ 动态内存管理：`new/delete`

C++ 中推荐使用：

```cpp
new
delete
new[]
delete[]
```

### 1. 操作内置类型

```cpp
int* p1 = new int;
int* p2 = new int(10);
int* p3 = new int[3];

delete p1;
delete p2;
delete[] p3;
```

注意匹配：

| 申请 | 释放 |
|---|---|
| `new` | `delete` |
| `new[]` | `delete[]` |

一定要匹配使用。

---

### 2. 操作自定义类型

```cpp
class A
{
public:
    A() { cout << "A()" << endl; }
    ~A() { cout << "~A()" << endl; }
};

A* p = new A;
delete p;
```

核心区别：

- `new A`：申请空间 + 调用构造函数。
- `delete p`：调用析构函数 + 释放空间。

而：

```cpp
A* p = (A*)malloc(sizeof(A));
free(p);
```

只会申请和释放空间，不会调用构造和析构。

---

## 六、`operator new` 和 `operator delete`

重点区分：

| 名称 | 本质 |
|---|---|
| `new` | 操作符，用户使用 |
| `delete` | 操作符，用户使用 |
| `operator new` | 全局函数，底层负责申请空间 |
| `operator delete` | 全局函数，底层负责释放空间 |

`new` 的底层会调用 `operator new`。  
`delete` 的底层会调用 `operator delete`。

大致关系：

```text
new -> operator new -> malloc

delete -> operator delete -> free
```

`operator new` 申请失败时通常会抛出 `bad_alloc` 异常，而不是像 `malloc` 那样返回 `NULL`。

---

## 七、`new/delete` 实现原理

### 1. 内置类型

对于内置类型：

```cpp
int* p1 = (int*)malloc(sizeof(int));
int* p2 = new int;
```

差别相对较小。

主要区别：

- `malloc` 失败返回 `NULL`。
- `new` 失败抛异常。
- `new` 写法更简单，不用手动计算字节数和强转。

---

### 2. 自定义类型的 `new` 原理

```cpp
A* p = new A(10);
```

步骤：

1. 调用 `operator new` 申请空间。
2. 在申请到的空间上调用构造函数，完成对象构造。

---

### 3. 自定义类型的 `delete` 原理

```cpp
delete p;
```

步骤：

1. 调用析构函数，清理对象内部资源。
2. 调用 `operator delete` 释放对象空间。

---

### 4. `new T[N]` 原理

```cpp
A* p = new A[10];
```

步骤：

1. 调用 `operator new[]` 申请连续空间。
2. 实际底层会调用 `operator new`。
3. 对 N 个对象分别调用构造函数。

---

### 5. `delete[]` 原理

```cpp
delete[] p;
```

步骤：

1. 对 N 个对象分别调用析构函数。
2. 调用 `operator delete[]` 释放空间。
3. 实际底层会调用 `operator delete`。

---

## 八、定位 new：`placement new`

定位 `new` 的作用：

> 在已经分配好的原始内存空间上调用构造函数初始化对象。

格式：

```cpp
new(place_address) Type;
new(place_address) Type(initializer-list);
```

示例：

```cpp
A* p = (A*)malloc(sizeof(A));
new(p) A(10);
p->~A();
free(p);
```

解释：

1. `malloc` 只申请一段原始空间，还不是对象。
2. `new(p) A(10)` 在这段空间上调用构造函数。
3. `p->~A()` 显式调用析构函数。
4. `free(p)` 释放空间。

使用场景：

> 常和内存池配合使用。内存池只提供原始内存，自定义类型对象还需要显式构造。

---

## 九、`malloc/free` 和 `new/delete` 的区别

共同点：

> 都是从堆上申请空间，都需要用户手动释放。

区别：

| 对比项 | `malloc/free` | `new/delete` |
|---|---|---|
| 本质 | 函数 | 操作符 |
| 空间大小 | 手动计算字节数 | 根据类型自动计算 |
| 返回类型 | `void*`，C++ 中需强转 | 返回对应类型指针 |
| 初始化 | `malloc` 不初始化，`calloc` 清零 | `new` 可以初始化 |
| 失败处理 | 返回 `NULL` | 抛异常 |
| 自定义类型 | 不调用构造 / 析构 | 自动调用构造 / 析构 |
| 数组申请 | 手动算总大小 | `new[]` 指定对象个数 |
| 释放方式 | `free` | `delete` / `delete[]` |

最重要区别：

> 对自定义类型，`new/delete` 会调用构造函数和析构函数，`malloc/free` 不会。

## 十、易错点汇总

1. `char arr[] = "abcd"` 的内容在栈上，`const char* p = "abcd"` 指向常量区。
2. 指针变量本身在哪里，看它怎么定义；它指向哪里，看它保存的地址来自哪里。
3. `malloc` 申请失败返回 `NULL`，`new` 失败抛异常。
4. `new` / `delete` 要配对，`new[]` / `delete[]` 要配对。
5. `malloc/free` 不会调用构造和析构。
6. `operator new` 不是 `new` 操作符本身，而是底层申请空间的函数。
7. 定位 `new` 只调用构造函数，不负责申请空间。
8. 用定位 `new` 构造的对象，需要手动调用析构函数。

## 十一、一页纸记忆版

- **栈：局部变量、参数、返回值。**
- **堆：动态申请空间。**
- **数据段：全局变量、静态变量。**
- **代码段 / 常量区：代码、只读常量、字符串常量。**
- **`malloc/free` 是函数，只管空间。**
- **`new/delete` 是操作符，既管空间，也管构造和析构。**
- **内置类型下，`new/delete` 和 `malloc/free` 差别较小。**
- **自定义类型下，差别巨大：构造和析构是否自动调用。**
- **`new` 底层调用 `operator new`，`operator new` 通常再调用 `malloc`。**
- **`delete` 先析构，再调用 `operator delete` 释放空间。**
- **定位 `new` 是在已有空间上显式构造对象。**
