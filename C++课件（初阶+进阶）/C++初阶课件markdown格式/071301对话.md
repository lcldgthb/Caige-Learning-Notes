1. 学“类的定义”后，马上写一个最小类

class Date
{
public:
    void Print()

    int _year;

你应该马上实践：

#include <iostream>
using namespace std;

class Date
{
public:
    void Print()
    {
        cout << _year << "-" << _month << "-" << _day << endl;
    }

private:
    int _year = 2026;
    int _month = 7;
    int _day = 15;
};

int main()
{
    Date d;
    d.Print();

    return 0;
}

然后问自己：

1. 为什么 main 里面不能直接访问 d._year？
2. public 和 private 有什么区别？
3. 如果把 Print 放到 private 里会怎样？
4. class 默认访问权限是什么？
5. struct 默认访问权限是什么？

这就是“通过实践学习”。

2. 学 this 指针后，故意写一个容易错的版本

比如：

class Date
{
public:
    void Init(int year, int month, int day)
    {
        year = year;
        month = month;
        day = day;
    }

    void Print()
    {
        cout << _year << "-" << _month << "-" << _day << endl;
    }

private:
    int _year;
    int _month;
    int _day;
};

然后你运行看看，发现结果不对。

再改成：

void Init(int year, int month, int day)
{
    _year = year;
    _month = month;
    _day = day;
}

或者：

void Init(int year, int month, int day)
{
    this->_year = year;
    this->_month = month;
    this->_day = day;
}

这样你对 this 指针的理解会比单纯听课深很多。

这类练习非常适合 C++。

4. 改错型实践

目标：看一段有问题的代码，找出错误并修复。

比如：

class Stack
{
public:
    Stack(int capacity)
    {
        _a = new int[capacity];
        _top = 0;
        _capacity = capacity;

private:

    int _top;
    int _capacity;
};

你要问：

这段代码有没有问题？
有没有内存泄漏？
需不需要析构函数？
需不需要拷贝构造？
需不需要赋值重载？

这类题比单纯概念题更接近真实开发。

- xxx
