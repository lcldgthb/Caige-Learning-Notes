# 一、`pwd` 指令与 Linux 文件结构

## 1.1 `pwd` 指令介绍

`pwd` 全称：

> **Print Working Directory**

作用：**显示当前所在目录的绝对路径**。

```bash
pwd
```

例如：

```bash
[root@localhost ~]# pwd
/root
```

说明当前所在位置是：

```text
/root
```

如果进入 `/home`：

```bash
cd /home
pwd
```

结果：

```text
/home
```

### 为什么需要 `pwd`？

因为 Linux 操作过程中，你经常会不知道：

> **我现在到底在哪？**

这时候直接：

```bash
pwd
```

即可。

---

# 1.2 Linux 的文件结构

Linux 和 Windows 最大的区别之一，就是**文件系统结构不同**。

Windows：

```text
C:\
D:\
E:\
```

Linux：

```text
/
```

只有一个最高级的根目录：

```text
/
```

所有文件和目录都从 `/` 开始。

例如：

```text
/
├── bin
├── boot
├── dev
├── etc
├── home
├── lib
├── root
├── tmp
├── usr
└── var
```

可以把 `/` 理解成 Linux 文件系统的**根**。

---

## 常见目录

### `/`

根目录。

```text
/
```

整个 Linux 文件系统的最顶层。

---

### `/root`

root 用户的家目录。

```text
/root
```

如果你现在登录的是 root：

```bash
pwd
```

很可能得到：

```text
/root
```

---

### `/home`

普通用户的家目录通常放在这里。

例如：

```text
/home/zhangsan
/home/lisi
```

---

### `/bin`

存放很多常用的 Linux 命令。

例如：

```text
ls
cp
mv
```

不过需要注意：现代 Linux 中 `/bin` 往往是 `/usr/bin` 的符号链接或与其合并。

---

### `/etc`

存放系统和各种软件的**配置文件**。

例如：

```text
/etc/passwd
/etc/hosts
/etc/ssh/
```

Linux 学到后面，`/etc` 会经常出现。

---

### `/tmp`

临时文件目录。

很多程序运行过程中会产生临时文件。

---

### `/usr`

存放大量用户空间程序、库、文档等。

例如：

```text
/usr/bin
/usr/lib
/usr/include
```

---

### `/var`

存放经常变化的数据。

比如日志：

```text
/var/log
```

以后学 Linux 服务的时候会经常查看：

```bash
/var/log/
```

---

# 二、`ls` 指令与常用选项

## 2.1 `ls` 的使用

`ls`：

> **list**

作用：**查看目录中的文件和目录。**

最简单：

```bash
ls
```

例如：

```text
[root@localhost ~]# ls
Desktop  Documents  Downloads  test.txt
```

表示当前目录中有：

```text
Desktop
Documents
Downloads
test.txt
```

---

## `ls -l`

这是非常重要的选项。

```bash
ls -l
```

例如：

```text
-rw-r--r-- 1 root root 1234 Sep  9 20:00 test.txt
drwxr-xr-x 2 root root 4096 Sep  9 20:01 test
```

可以看到更加详细的信息。

每一列大致表示：

```text
权限   硬链接数   用户   用户组   大小   时间   文件名
```

例如：

```text
-rw-r--r-- 1 root root 1234 Sep 9 20:00 test.txt
```

---

## `ls -a`

```bash
ls -a
```

`a` = **all**

显示**所有文件，包括隐藏文件**。

Linux 中隐藏文件通常以：

```text
.
```

开头。

例如：

```text
.bashrc
.profile
```

所以：

```bash
ls
```

可能看不到：

```text
.bashrc
```

而：

```bash
ls -a
```

就能看到。

---

## `ls -al`

实际开发中非常常用：

```bash
ls -al
```

就是：

```text
-a
```

*

```text
-l
```

即：

> **显示所有文件，并以详细格式显示。**

---

## `ls -lh`

```bash
ls -lh
```

`h` = human-readable

让文件大小更容易阅读。

例如普通：

```text
1048576
```

可能显示成：

```text
1.0M
```

所以经常使用：

```bash
ls -lh
```

---

## `ls 目录名`

可以直接查看指定目录：

```bash
ls /home
```

而不是必须先：

```bash
cd /home
ls
```

# 2.2 Linux 中的文件初步介绍

Linux 中有一个非常重要的概念：

> **一切皆文件**

普通文件：

```text
test.txt
```

目录：

```text
test/
```

设备：

```text
/dev/
```

甚至很多系统资源也通过文件形式提供。

## 文件名

Linux 文件名可以包含很多字符，但实际开发中建议：

```text

```

# 三、`mkdir` 指令——新建文件夹

`mkdir`：

> **make directory**

作用：

> 创建目录。

---

## 3.1 `mkdir` 的使用

最基本：

```bash
mkdir test
```

创建：

```text
test/
```

查看：

```bash
ls
```

可以看到：

```text
test
```

---

## 一次创建多个目录

```bash
mkdir test1 test2 test3
```

会同时创建：

```text
test1
test2
test3
```

---

## 创建多级目录

假设：

```bash
mkdir a/b/c
```

如果 `a` 不存在，就会报错：

```text
No such file or directory
```

这时候使用：

```bash
mkdir -p a/b/c
```

`-p` 非常重要。

它会自动创建不存在的父目录：

```text
a
└── b
    └── c
```

所以：

```bash
mkdir -p a/b/c
```

是实际使用中非常常见的命令。

---

# 3.2 `mkdir` 的常用选项

最重要的就是：

```bash
mkdir -p
```

例如：

```bash
mkdir -p project/src/test
```

即使：

```text
project
src
test
```

都不存在，也可以一次创建。

# 四、`touch` 指令与时间戳

`touch` 是一个非常重要的命令。

它主要有两个常见用途：

1. **创建空文件**
2. **修改文件时间戳**

---

# 4.1 `touch` 的使用

## 创建新文件

```bash
touch test.txt
```

如果：

```text
test.txt
```

不存在，就会创建一个空文件。

然后：

```bash
ls
```

可以看到：

```text
test.txt
```

---

## 一次创建多个文件

```bash
touch a.txt b.txt c.txt
```

一次创建三个文件。

---

# 4.1.1 创建新文件

这里需要特别注意：

```bash
touch test.txt
```

创建的是：

> **空文件**

它不会自动帮你写入内容。

如果想编辑：

```bash
vim test.txt
```

或者：

```bash
echo "hello" > test.txt
```

---

# 4.1.2 修改文件的时间

Linux 文件有几个重要时间属性。

使用：

```bash
stat test.txt
```

可以看到详细信息。

例如：

```text
Access
Modify
Change
```

最常见的是：

### Access Time

访问时间：

```text
atime
```

### Modify Time

内容修改时间：

```text
mtime
```

### Change Time

文件属性/元数据发生变化的时间：

```text
ctime
```

---

如果：

```bash
touch test.txt
```

文件已经存在，那么它通常**不会清空文件内容**，而是更新文件的时间属性。

这是一个非常重要的知识点。

---

# 4.2 时间戳的概念补充

你可以把时间戳简单理解成：

> Linux 用来记录文件相关操作时间的信息。

例如：

```bash
stat test.txt
```

以后学习 Linux 时经常会看到：

```text
Access
Modify
Change
Birth
```

不过在 Linux 中不要简单地把 `ctime` 理解成“创建时间”。

**`ctime` 不是 creation time，而是 change time。**

这一点考试和面试都可能问。

# 五、`cd` 指令与 Linux 中的路径

`cd`：

> **change directory**

作用：

> 切换当前工作目录。

---

# 5.1 `cd` 的使用

例如当前：

```text
/root
```

执行：

```bash
cd /home
```

然后：

```bash
pwd
```

得到：

```text
/home
```

说明已经进入 `/home`。

---

## 返回上一级

```bash
cd ..
```

例如：

```text
/home/user
```

执行：

```bash
cd ..
```

变成：

```text
/home
```

这里：

```text
..
```

表示：

> **上一级目录**

---

## 当前目录

```text
.
```

表示：

> **当前目录**

例如：

```bash
./test
```

表示当前目录下的 `test`。

---

## 返回家目录

```bash
cd ~
```

`~` 表示当前用户的家目录。

如果你是 root：

```text
~
```

通常就是：

```text
/root
```

如果普通用户：

```text
/home/用户名
```

---

## 直接回家

还有一个非常方便的：

```bash
cd
```

不带任何参数。

通常等价于：

```bash
cd ~
```

---

# 5.2 Linux 中的路径

路径主要分为两种：

## 相对路径

相对于：

> **当前所在目录**

例如当前：

```text
/home/user
```

执行：

```bash
cd test
```

实际上进入：

```text
/home/user/test
```

---

## 绝对路径

从：

```text
/
```

开始描述。

例如：

```bash
cd /home/user/test
```

这就是绝对路径。

---

# 5.2.1 相对路径和绝对路径

假设目录结构：

```text
/
└── home
    └── user
        ├── test
        └── code
```

当前在：

```text
/home/user
```

那么：

```bash
cd test
```

是相对路径。

而：

```bash
cd /home/user/test
```

是绝对路径。

---

### 一个非常重要的判断方法

**看路径是不是以 `/` 开头。**

```text
/home/user/test
```

绝对路径。

```text
test
./test
../test
```

相对路径。

---

# 5.3 这个目录到底该怎么写

这里重点就是理解：

```text
.
..
~
/
```

| 符号   | 含义      |
| ---- | ------- |
| `/`  | 根目录     |
| `.`  | 当前目录    |
| `..` | 上一级目录   |
| `~`  | 当前用户家目录 |

例如：

```bash
cd ..
```

向上一级。

```bash
cd .
```

还是当前目录。

```bash
cd ~
```

回家。

```bash
cd /
```

回到根目录。

# 六、`rm` 删除指令、`rmdir` 与通配符

这一部分非常重要。

尤其是：

> **`rm -rf` 是 Linux 初学者一定要谨慎使用的命令。**

---

# 6.1 `rm` 指令——一把双刃剑

`rm`：

> **remove**

作用：

> 删除文件或目录。

删除文件：

```bash
rm test.txt
```

---

## 删除多个文件

```bash
rm a.txt b.txt c.txt
```

---

## `rm -i`

```bash
rm -i test.txt
```

`-i`：

> interactive

删除之前询问：

```text
rm: remove regular file 'test.txt'? 
```

输入：

```text
y
```

才删除。

对于新手来说非常有用。

---

# `rm -r`

如果删除目录：

```bash
rm test
```

通常会提示：

```text
Is a directory
```

因为 `rm` 默认主要用于删除文件。

删除目录及其里面的内容：

```bash
rm -r test
```

`r`：

> recursive

递归删除。

例如：

```text
test
├── a.txt
├── b.txt
└── sub
    └── c.txt
```

执行：

```bash
rm -r test
```

整个：

```text
test
```

都会被删除。

---

# `rm -f`

```bash
rm -f test.txt
```

`f`：

> force

强制删除，不进行普通的确认提示。

---

# `rm -rf`

```bash
rm -rf test
```

相当于：

```text
-r
递归

-f
强制
```

所以：

> **强制递归删除目录及其全部内容。**

例如：

```bash
rm -rf test
```

可能直接把：

```text
test/
├── a
├── b
└── c
```

全部删除。

**Linux 中没有 Windows 回收站式的默认保护。**

因此千万不要随便执行：

```bash
rm -rf /*
```

这类命令。

---

# 6.2 `rmdir`——删除空目录

`rmdir`：

> remove directory

但是它有一个特点：

> **只能删除空目录。**

例如：

```text
test/
```

里面什么都没有：

```bash
rmdir test
```

可以删除。

但如果：

```text
test/
└── a.txt
```

执行：

```bash
rmdir test
```

就会失败。

因为目录不是空的。

这时候可以：

```bash
rm -r test
```

---

## `rm` 和 `rmdir` 的区别

| 命令           | 作用       |
| ------------ | -------- |
| `rm file`    | 删除文件     |
| `rm -r dir`  | 删除目录及其内容 |
| `rm -rf dir` | 强制递归删除目录 |
| `rmdir dir`  | 删除空目录    |

---

# 6.3 模糊操作——`*` 通配符

这个非常重要。

```text
*
```

叫：

> 通配符（wildcard）

表示：

> **匹配任意多个字符。**

例如：

```text
a.txt
b.txt
c.txt
test.cpp
main.cpp
```

执行：

```bash
ls *.txt
```

会匹配：

```text
a.txt
b.txt
c.txt
```

---

## `*.cpp`

```bash
ls *.cpp
```

匹配所有 `.cpp` 文件：

```text
main.cpp
test.cpp
hello.cpp
```

---

## `test*`

```bash
ls test*
```

可以匹配：

```text
test
test.txt
test.cpp
testing
```

---

## `*`

```bash
ls *
```

匹配当前目录下的很多非隐藏项目。

---

### 通配符不仅能用于 `ls`

例如：

```bash
rm *.txt
```

表示：

> 删除当前目录下所有 `.txt` 文件。

所以一定要注意：

```bash
rm *.txt
```

删除的是一批文件，而不是一个文件。

```text
↑
```

可以调出上一条命令：

```bash

```

再按：

```text
↑
```

得到：

```bash

```

继续：

```text
↑
```

得到：

```bash
mkdir test
```

所以：

> **↑ / ↓ 可以快速浏览历史命令。**

这个功能你以后会天天用。
