# 聊天 Linux 开发工具 —— 预习导读

> 用途：课前 10~15 分钟快速建立整体框架，带着问题和关键词去听课/读课件。
> 本课主线：**在 Linux 上，从「装好工具」到「写出、编译、调试、管理一个 C/C++ 程序」的完整工作流。**

---

## 全课地图

```
软件包管理(yum/apt) → 编辑器(vim) → 编译器(gcc/g++) → 构建工具(make/Makefile)
        → 小程序练手(进度条) → 版本管理(git) → 调试器(gdb/cgdb)
```

一条线串起来：**装软件 → 写代码 → 编译 → 自动化构建 → 动手验证 → 版本存档 → 出错了能调试**。

---

## 第 1 章 软件包管理器（yum / apt）

- **核心主题**：Linux 怎么装、删、查软件？软件包、软件源、包管理器三者的关系。
- **关键术语**：软件包(Package)、软件源/仓库(Repository)、包管理器、yum（CentOS，RPM 系）、apt（Ubuntu，DEB 系）、`.repo` 文件、镜像源、EPEL。
- **学习要点**：`yum/apt` 的 install / remove / list / search；为什么换国内镜像源会变快；`apt update` 和 `apt upgrade` 的区别。
- **带着这些问题去学**：
  1. 为什么 Linux 装软件通常不需要去官网下载安装包？
  2. 「软件源」本质上是服务器的什么配置？改哪个目录下的文件？
  3. CentOS 7 停止维护后，官方源还能用吗？要去哪里找旧包？

## 第 2 章 Vim 编辑器

- **核心主题**：多模式编辑器——为什么 vim 要分模式？三种模式怎么切、各自干什么？
- **关键术语**：普通模式(Normal)、插入模式(Insert)、底行/末行模式(Last-line)、`~/.vimrc` 配置文件。
- **学习要点**：模式切换（`i/a/o`、`Esc`、`:`）；普通模式的光标移动（`hjkl`、`w/b`、`gg/G`、`0/$`）、删除/复制/粘贴/撤销（`x/dd/yy/p/u`）；底行模式的保存退出查找替换（`:w :q :wq /xxx :%s`）；「动作 + 范围」的组合思想（如 `d3w`）。
- **带着这些问题去学**：
  1. vim 为什么不让普通模式下直接打字？这样设计换来什么好处？
  2. 复制 5 行、撤销误删、全文替换一个词，分别按什么键？
  3. 如何让 vim 每次打开都自动显示行号？

## 第 3 章 gcc/g++ 编译器

- **核心主题**：一个 `.c` 文件是怎么变成可执行程序的？编译的四个阶段。
- **关键术语**：预处理、编译、汇编、链接；`-E -S -c -o -g -Wall -std= -O`；头文件路径 `-I`、库路径 `-L`、库名 `-l`；静态链接 vs 动态链接；静态库 `.a` 与动态库 `.so`。
- **学习要点**：四阶段各自产什么文件（`.i/.s/.o/可执行`）；动静态链接的区别与代价；`ldd` 看依赖；`LD_LIBRARY_PATH` 的作用。
- **带着这些问题去学**：
  1. `#include <stdio.h>` 里的代码在编译的哪个阶段被"展开"进来？
  2. 为什么加了 `-g` 才能用 gdb 调试？
  3. 动态链接的程序换台机器跑不起来，可能是什么原因？

## 第 4 章 make / Makefile

- **核心主题**：项目文件一多，一条条敲 gcc 太累——让 make 决定"编译什么、按什么顺序编译"。
- **关键术语**：目标(target)、依赖(dependency)、规则、默认目标、伪目标 `.PHONY`、时间戳增量编译、变量 `CC/CFLAGS`、自动变量 `$@ $^ $<`。
- **学习要点**：`目标: 依赖` + Tab 开头命令的基本语法；make 如何根据文件修改时间决定是否重编；多文件项目的依赖链与递归推导；`make clean` 为什么通常写成伪目标。
- **带着这些问题去学**：
  1. gcc 和 make 的分工是什么？（"怎么编" vs "何时编、编哪些"）
  2. 只改了一个 `.c` 文件，make 凭什么知道只需重编它？
  3. Makefile 里的命令为什么必须用 Tab 缩进，空格行不行？

## 第 5 章 进度条小程序

- **核心主题**：用一个小项目练手，顺便搞懂回车换行与输出缓冲。
- **关键术语**：`\r`（回车，回到行首）vs `\n`（换行）、行缓冲区、`fflush(stdout)`、`usleep`。
- **学习要点**：为什么打印不换行时内容可能"卡住"不显示；倒计时与进度条的实现思路。
- **带着这些问题去学**：
  1. 进度条为什么能在同一行不断更新，而不是一行行刷屏？
  2. `printf` 之后不 `fflush`，屏幕上看不到内容，数据去哪了？

## 第 6 章 Git 版本管理

- **核心主题**：代码的"存档系统"——为什么需要版本控制？Git 和 GitHub 是不是一回事？
- **关键术语**：版本控制(VCS)、工作区、暂存区、本地仓库、远程仓库、commit、Commit ID（哈希）、分布式。
- **学习要点**：四区模型与代码流向（工作区→暂存区→本地仓库→远程仓库）；`init/status/add/commit/push/pull/clone/log/diff` 的用途。
- **带着这些问题去学**：
  1. commit 像游戏存档——那么 `add`（暂存）这一步为什么存在，能不能省？
  2. 「分布式」相比「集中式」版本控制，断网时差别体现在哪？
  3. 改坏了代码想对比改动，`status` 和 `diff` 分别告诉你什么？

## 第 7 章 gdb / cgdb 调试器

- **核心主题**：程序出错了不靠猜——用调试器单步走、看变量、设断点。
- **关键术语**：断点(breakpoint)、单步（`next` 逐过程 / `step` 逐语句）、查看变量 `p`、调用栈 `bt`、条件断点、`watch`。
- **学习要点**：编译必须带 `-g` 且建议 `-O0`；常用命令 `l/b/r/n/s/c/p/info break/delete/bt/q`；`next` 与 `step` 的区别；断点不会修改源代码。
- **带着这些问题去学**：
  1. 想让循环跑到第 99999 次才停下来检查，怎么设断点才不累死？
  2. 程序崩在深层函数里，怎么知道它是被谁一路调进来的？

## 附录 换软件源（CentOS / Ubuntu）

- **核心主题**：默认源在国外太慢/已停更，如何换国内镜像源。
- **关键术语**：镜像站（阿里云/清华/中科大）、Vault 存档库、old-releases、`sources.list`。
- **学习要点**：换源的基本套路（备份原文件 → 写入新源地址 → 刷新缓存）；CentOS 7 与 Ubuntu 20.04 的特殊性（都已过支持期，源地址不同）。
