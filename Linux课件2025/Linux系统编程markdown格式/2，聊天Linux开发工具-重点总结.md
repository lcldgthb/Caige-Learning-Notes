## 一、软件包管理器

### 1. 核心概念
- **软件包**：程序 + 配置 + 依赖信息的打包；CentOS 为 **RPM**(`.rpm`)，Ubuntu 为 **DEB**(`.deb`)
- **软件源/仓库(Repository)**：集中存放软件包的服务器
- **包管理器**：自动完成"找包→下载→解依赖→安装"：**yum**（CentOS）/ **apt**（Ubuntu）
- **EPEL**：社区维护的官方扩展源

### 2. 命令对照
| 操作 | yum (CentOS) | apt (Ubuntu) |
|---|---|---|
| 列出 | `yum list \| grep xxx` | `apt list` |
| 搜索 | `yum search xxx` | `apt search xxx` |
| 安装 | `sudo yum install -y xxx` | `sudo apt install -y xxx` |
| 卸载 | `sudo yum remove -y xxx` | `sudo apt remove -y xxx` |

- **`apt update` = 刷新索引**（不升级软件）；**`apt upgrade` = 真正升级**；先 update 后 upgrade
- 装/删需 **root 权限**；同时只能运行一个包管理进程

### 3. 安装源
- yum 源配置目录：**`/etc/yum.repos.d/*.repo`**；核心字段：**baseurl**（仓库地址）、**enabled**、**gpgcheck**（签名校验，勿关）
- **换源本质 = 把 baseurl 换成国内镜像地址**（阿里云/清华/中科大）
- Ubuntu 源文件：**`/etc/apt/sources.list`**
- **CentOS 7 已 EOL（2024-06-30）**：官方源下线，旧包在 **Vault** 存档站
- **Ubuntu 20.04 标准支持已结束（2025-05-31）**：源迁至 **old-releases.ubuntu.com**

## 二、Vim 编辑器

### 1. 三模式与切换
- **普通模式**（默认，命令中心）→ **插入模式**：`i`（光标前）/ `a`（光标后）/ `o`（下开新行）；`I/A/O` 行首/行尾/上开新行
- 任何模式 → 普通模式：**`Esc`**（迷路就狂按）
- 普通模式 → **底行模式**：**`:`**

### 2. 普通模式命令
- 移动：**`hjkl`**（左下上右）、**`w/b`**（下/上一词）、**`0/^/$`**（行首/非空首/行尾）、**`gg/G`**（文件首/尾）、**`nG`**（跳第 n 行）
- 删除：**`x`**（删字符）、**`dd`**（剪切行）、**`dw`**（删词）；数字前缀：`ndd` 删 n 行
- 复制粘贴：**`yy`**（复制行）、**`nyy`**、**`p/P`**（粘到后/前）
- 撤销重做：**`u`**（撤销）、**`Ctrl+r`**（重做）
- 其他：**`r`+字符**（替换单字符）、**`cw`**（改词）、**`~`**（大小写切换）
- **组合思想：动作 + 范围**（`d$`=删到行尾、`y3w`=复制 3 词）

### 3. 底行模式命令
- **`:w` `:q` `:wq` `:q!`**：保存/退出/保存退出/强制不保存退出
- **`/xxx`** 查找，`n` 下一个、`N` 上一个
- 替换：**`:s/old/new/`**（当前行首个）、**`:s/old/new/g`**（当前行全部）、**`:%s/old/new/g`**（全文）
- **`:set nu`** 显示行号；**`:n`** 跳第 n 行；**`:!命令`** 临时执行 shell

### 4. 配置
- 配置文件：**`~/.vimrc`**（每用户一份，启动自动加载）
- 常用：`set nu`、`set tabstop=4`、`set autoindent`、`syntax on`

## 三、gcc/g++ 编译器

### 1. 编译四阶段（必背）
| 阶段 | 选项 | 产物 | 工作 |
|---|---|---|---|
| 预处理 | **`-E`** | `.i` | 展开头文件、宏替换、去注释 |
| 编译 | **`-S`** | `.s` | C → 汇编 |
| 汇编 | **`-c`** | `.o` | 汇编 → 机器码 |
| 链接 | 默认 | 可执行 | 合并 .o 与库，定址 |

- **报错定位**：找不到头文件=预处理/编译期；找不到函数实现=链接期

### 2. 动态 vs 静态链接
| | 动态 | 静态 |
|---|---|---|
| 库文件 | **`.so`** | **`.a`** |
| 方式 | 运行时找共享库 | 库代码拷进可执行 |
| 体积/依赖 | 小 / 依赖目标机有 .so | 大 / 零依赖 |

- gcc **默认动态链接**；`-static` 强制静态
- **`ldd ./程序`**：查动态库依赖；找不到库用 **`LD_LIBRARY_PATH`**

### 3. 库制作与链接选项
- 静态库：`ar -rc libxxx.a *.o`；动态库：`-fPIC` 编译 + `-shared` 链接
- **`-I`**：头文件搜索路径；**`-L`**：库文件搜索路径；**`-lxxx`**：链接 `libxxx.a/.so`

### 4. 常用选项
- **`-o`** 输出名、**`-g`** 调试信息、**`-Wall`** 开警告、**`-std=`** 语言标准、**`-O0~O3`** 优化级别
- **调试必须 `-g` + `-O0`**（优化会让行号/变量错乱）

## 四、make / Makefile

### 1. 分工
- **gcc 解决"怎么编"；make 解决"何时编、编哪些、什么顺序"**

### 2. 基本语法
```makefile
目标: 依赖
<Tab>命令
```
- **命令行首必须是 Tab，不能是空格**

### 3. 工作原理（四条结论）
- **默认目标**：`make` 只构建第一个目标
- **递归推导**：依赖不存在时自动找规则先造依赖，自底向上执行
- **时间戳增量编译**：依赖比目标新才重编；没改动报 `is up to date`；强制重编先 `make clean`
- **`.PHONY`**：声明伪目标（如 clean），防止同名文件干扰，保证永远执行

### 4. 变量
- 自定义：`CC = gcc`，引用 `$(CC)`
- 自动变量：**`$@`**=目标、**`$^`**=全部依赖、**`$<`**=第一个依赖
- 头文件要写入依赖（头文件变更需触发重编）

## 五、进度条（两个原理）

### 1. 回车换行
- **`\r`（回车，0x0D）= 回到本行行首**，不换行 → 后续输出覆盖本行（进度条原地刷新的原理）
- **`\n`（换行，0x0A）= 下一行**；C 中 `\n` 同时完成回车+换行

### 2. 行缓冲区
- stdout 默认**行缓冲**：遇 `\n` 或缓冲满才上屏
- 无 `\n` 时需 **`fflush(stdout)`** 强制刷新

### 3. 关键代码要点
- 倒计时：`printf("%2d\r", i)` + `fflush` + `sleep(1)`
- 进度条：`printf("[%-100s][%3d%%]\r", bar, i)`；`%-100s` 左对齐定宽、`%%` 输出 `%`
- `usleep` 单位是**微秒**

## 六、Git 版本管理

### 1. 概念
- **VCS**：记录每次改动、可回退任意版本
- **Git ≠ GitHub**：Git 是本地工具，GitHub/Gitee 是托管网站
- **分布式**：本地有完整仓库与历史，断网可 commit，联网再同步
- **`.git` 目录** = 仓库本体，删则历史全丢；**Commit ID** = 每次提交的哈希坐标

### 2. 四区模型（必背）
```
工作区 --add--> 暂存区 --commit--> 本地仓库 --push--> 远程仓库
                                                  <--pull/clone--
```
- **commit = 存档点**；暂存区用于凑齐一次完整改动再提交

### 3. 命令
| 命令 | 作用 |
|---|---|
| `git init` / `git clone <url>` | 初始化 / 克隆远程仓库 |
| `git status` | 查看改动与暂存状态（最高频） |
| `git add 文件` / `git add .` | 工作区→暂存区 |
| `git commit -m "说明"` | 暂存区→本地仓库 |
| `git log`（`--oneline`） | 提交历史 |
| `git diff` | 查看具体改动 |
| `git push` / `git pull` | 推送 / 拉取合并 |

- 工作流口诀：**改 → add → commit → push**

## 七、gdb / cgdb 调试器

### 1. 前提
- 编译带 **`-g` + `-O0`**；cgdb 是 gdb 的源码常显增强外壳，命令兼容

### 2. 命令表（必背）
| 命令 | 作用 |
|---|---|
| `l [行号]` | 查看源码 |
| `b 行号/函数名` | 设断点 |
| `info break` | 查看断点 |
| `r` | 运行至断点 |
| **`n`** | 单步逐过程（**跨过**函数） |
| **`s`** | 单步逐语句（**进入**函数） |
| `c` | 继续到下一断点 |
| `p 变量` | 打印变量（结果编号 `$1` 可复用） |
| `display` / `undisplay 编号` | 每步自动显示 / 取消 |
| `bt` | 查看调用栈 |
| `delete 编号` | 删断点 |
| `q` | 退出 |

- **直接回车 = 重复上一条命令**
- **条件断点**：`b 10 if i == 99999`；已有断点补条件：`condition 1 i == 99999`
- **`watch 变量`**：值一变即停；**`set var i = 100`**：调试中改变量
- **断点不修改源代码**

### 3. 崩溃排查套路
**`r` 跑崩 → `bt` 定位 → 断点前移 → `n/s` + `p` 逼近元凶**
