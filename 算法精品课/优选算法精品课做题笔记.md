###### 🔍 问题核心原因

你的代码使用了默认的 `priority_queue<pair<int, string>>`，它是**大顶堆**，比较逻辑是：

1. 先比较频率（`pair` 的第一个元素），频率高的优先；

2. 若频率相同，会按字符串**字典序降序**排列（`"love"` 字典序比 `"i"` 大，所以会先弹出），这和题目要求「频率相同时字典序小的在前」完全相反。

###### ✅ 修正后代码（自定义比较器）

```C++
class Solution {
private:// 自定义比较器：实现「频率高优先，频率相同则字典序小优先」struct Compare {bool operator()(const pair<int, string>& a, const pair<int, string>& b) {if (a.first != b.first) {// 频率不同：大顶堆，频率高的在堆顶return a.first < b.first;} else {// 频率相同：字典序小的在堆顶，所以当a的字典序更大时，a应该在堆下方return a.second > b.second;}}};public:
    vector<string> topKFrequent(vector<string>& words, int k) {
        unordered_map<string, int> cnt;for (auto& word : words) {
            cnt[word]++; // 统计每个单词的出现次数}// 用自定义比较器创建大顶堆
        priority_queue<pair<int, string>, vector<pair<int, string>>, Compare> pq;for (auto& [word, freq] : cnt) {
            pq.emplace(freq, word); // 插入（频率，单词）}

        vector<string> res;while (k-- > 0 && !pq.empty()) {
            res.push_back(pq.top().second); // 取堆顶单词
            pq.pop();}return res;}};
```

---

###### 🧠 关键逻辑说明

1. **自定义比较器 ****`Compare`**：

    - 频率不同时：保持大顶堆特性，频率高的单词先弹出；

    - 频率相同时：让**字典序更小的单词**先弹出（比如 `"i"` 会在 `"love"` 前面），完全贴合题目要求。

2. **堆的使用**：

    - 遍历单词统计频率后，将 `(频率, 单词)` 插入堆；

    - 依次弹出堆顶 `k` 次，得到前 `k` 个高频单词，顺序就是题目要求的「频率降序，字典序升序」。

---

- **默认堆的字典序逻辑**：`pair<int, string>` 频率相同时，会按字符串**字典序降序**排列，和题目要求相反，必须自定义比较器；

错误 1：递归参数使用 `i++`（最严重）

```C++

```

- `i++` 是**后置自增**：**先把 i 的值传给函数，再让 i\+1**

找错

```C++
class Solution {
  static  bool cmp(int a,int b)
    {
        string sa=to_string(a);
        string sb=to_string(b);
        return sa+sb<sb+sa;

    }
public:
    string largestNumber(vector<int>& nums) {
      sort(nums.begin(),nums.end(),cmp);
      string ret;
      for(int i=nums.size()-1;i>=0;i--)
      {
        ret+=to_string(nums[i]);
      }
      return ret[0]=='0'?'0':ret;
    }
};
```
